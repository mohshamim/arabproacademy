# Arab Pro Academy

Next.js marketing site for Arab Pro Academy — spoken Arabic courses in Riyadh.

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS 4
- shadcn/ui (Button, Accordion, Input, Label)
- Lucide icons

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — start production server
